# دَارُ الحِكَايَاتِ — صفحة الهبوط الرسمية

<div dir="rtl">

صفحة الهبوط والتسويق الرسمية لتطبيق **دَارُ الحِكَايَاتِ** — محرابٌ مقدّس لفنّانة السرد، مشروع الكاتبة **رحمه السيد موافي**.

مبنية بهوية التطبيق الأصلية بالكامل: ألوان الرقّ والحبر والذهبيّ الزيتونيّ، خطوط ثمانية الرسمية، ولقطات حقيقية من التطبيق وهو يعمل.

## ✨ المزايا

- **هوية أصلية 100%** — مُستخرجة من كود التطبيق نفسه (`royal_classic` / `night_whisper` / `apple_dark`)
- **خطوط ثمانية الرسمية** — Serif Display / Serif Text / Sans (ملفات woff2 محلية، صفر طلبات خارجية)
- **لقطات حقيقية** — من التطبيق الفعلي: المحرر الغامر، المحراب (مواقيت الصلاة)، ووضع همس الليالي
- **أداء عالٍ** — ملف HTML واحد + أصول محلية، بدون أي framework أو تبعيات
- **متجاوبة بالكامل** — من 360px حتى الشاشات العريضة، RTL أصيل
- **وصولية** — احترام `prefers-reduced-motion`، تباين AA، تركيز ظاهر، وأدوار ARIA

## 🚀 النشر على Vercel

1. اعمل **Fork** أو استورد المستودع إلى حسابك
2. من [vercel.com/new](https://vercel.com/new) اختر المستودع
3. اضغط **Deploy** — لا يحتاج أي إعدادات بناء (موقع ثابت):

| الإعداد | القيمة |
|---|---|
| Framework Preset | `Other` |
| Build Command | *(فارغ)* |
| Output Directory | `./` |
